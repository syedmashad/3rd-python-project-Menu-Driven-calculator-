# 📑 3rd Python Project: Menu-Driven Calculator

An interactive, console-based Python application that uses a menu-driven interface to perform multiple operations continuously until the user explicitly exits.

---

## 🌟 Features
- 📜 **Interactive Menu**: Clear visual choices for quick navigation.
- 🔁 **Continuous Loop**: Run multiple calculations without restarting the script.
- 🔢 **Core Operations**: Addition, Subtraction, Multiplication, Division, and Modulus.
- 🚪 **Clean Exit**: Dedicated menu option to terminate the program smoothly.
- 🛡️ **Input Validation**: Safe handling of invalid choices and division by zero errors.
